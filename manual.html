3월새 학년 시작

설정 시트 → 현재학년도 바꾸기

설정 시트의 현재학년도 값을 새 연도로 (예: 2026 → 2027). 이걸 제일 먼저 하세요 — 학기초정리가 이 숫자를 보고 시트를 만들어요.

학기초정리 실행 — 빈 시트 생성

구글 시트 → 확장 프로그램 → Apps Script → 함수 목록에서 학기초정리 선택 → ▶ 실행.

새 연도의 성적_2027_1학년_1학기 같은 빈 시트와 진학_2028, 학생개인번호가 생겨요.

NEIS 명렬표 → 학생개인번호 시트

1·2·3학년 명렬표(학생개인번호 있는 것)를 합쳐서 붙여넣기. 열 순서: 학년 | 반 | 번호 | 학생이름 | 학번

재학생은 작년과 같은 번호, 신입생은 새 번호가 들어와요. 이 시트가 학번의 원천이에요.

학생정보 시트 → 새 명렬로 교체

기존 내용 지우고 새 학년 명렬 붙여넣기. 열 순서는 그대로:

A 학년B 반C 번호D 학생이름E 학생전화F 학부모전화G 주소H 학적I (빈칸)J 특이사항K 학번

K열 학번은 비워두세요. 학기초정리가 채워요.

졸업생은 여기서 빠지지만 성적·진학·사진은 학번으로 남아있어요.
담임 시트 → 새 담임

학년 | 반 | 담임이름. 반 개수가 바뀌면 GitHub의 index.html에서 CLASS_COUNT 숫자도 맞춰주세요.

신입생 사진 업로드

드라이브 학생사진/1-1/ 폴더에 지금처럼 이름(번호).jpg로. 학기초정리가 학번 폴더로 자동 복사해요.

재학생 사진은 이미 학번 폴더에 있으니 아무것도 안 해도 돼요.

신입생 중학교 성적 → 성적_중학교

기존 행 아래에 이어서 붙여넣기: (학번 빈칸) | 학년 | 반 | 번호 | 학생이름 | 출신중 | 중학교성적

학교 엑셀 형식이 다르면 Claude에게 파일을 주고 "시트 붙여넣기용으로 변환해줘" 하면 돼요.

학기초정리 한 번 더 — 학번·사진 정리

결과 팝업에서 못 찾음에 나온 학생만 확인하세요. 대개 이름 오타나 반·번호 불일치예요. 전학·자퇴생은 못 찾아도 정상.

학기말성적 추가 (7월 · 12월)

성적 파일 변환 요청

학교에서 받은 성적 엑셀(학년별 3개)을 Claude에게 올리고 "성적 시트 붙여넣기용으로 변환해줘". 학급코드·헤더 정리해서 돌려줘요.

해당 학기 시트에 붙여넣기

1학기 → 성적_2027_1학년_1학기, 2학기 → 성적_2027_1학년_2학기 (학년별 3개). 시트는 3월에 이미 만들어져 있어요. A1부터 통째로 붙여넣기.

앱은 시트 이름을 보고 자동으로 "1학년 2학기 내신 · 2027" 카드를 만들고, 성적순·전성적대비도 최신 학기 기준으로 바뀌어요.

학기초정리 실행 — 학번 채우기

이름이 학기초정리지만 아무 때나 실행해도 안전해요. 이미 채워진 건 건너뛰어요.

2월졸업생 진학 결과

진학_YYYY 시트에 결과 입력

YYYY = 대학 입학 연도. 3학년 명렬을 붙여넣고 진학대학, 학과 채우기. 열 순서:

학번학년반번호학생이름진학대학학과학생전화담임

학번·담임은 비워두세요. 대학명은 정확히 같은 글자로 (예: 연세대학교).

재수생 (작년 졸업생이 올해 입학): 학번 칸에 재수생이라고 쓰고 이름·대학·학과 입력 → 명단에 "재수" 뱃지로 표시.

재수·미진학·유학 등 대학이 없는 경우: 진학대학 칸에 그 단어를 쓰면 목록 맨 아래에 묶여요.

학기초정리 실행 — 3월 명렬 교체 전에!
3학년이 아직 학생정보 시트에 있을 때 실행해야 학번과 담임이 채워져요. 명렬을 먼저 바꾸면 못 찾아요.
대학순위 시트 정리 (선택)

앱 진학현황 목록은 이 시트 순서대로 나와요. 위로 올릴 대학은 줄을 위로. 시트에 없는 대학은 맨 아래 인원순. 부분 일치라 서울대만 써도 서울대학교에 맞아요.

수시그때그때

전입생이 왔을 때

① 학생개인번호 시트에 한 줄 추가 ② 학생정보에 한 줄 추가 (학번 빈칸) ③ 사진 업로드 ④ 학기초정리 실행.

전학·자퇴

앱에서 학생 카드 열고 학적 뱃지 눌러 바꾸면 끝. 시트를 직접 고칠 필요 없어요.

담임이 바뀌었을 때

담임 시트만 고치면 바로 반영. 진학 시트의 담임 칸은 졸업 당시 기록이라 안 바뀌어요.

문제안 될 때

GAS 코드를 고쳤는데 앱에 반영이 안 돼요

저장만으로는 안 돼요. Apps Script 우측 상단 배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포. (기존 URL 유지)

index.html을 고쳤는데 폰에서 옛날 화면이 나와요

GitHub의 service-worker.js 첫 줄 CACHE_NAME의 버전 숫자를 하나 올리고 커밋. 폰에서 앱 완전 종료 후 재실행.

어떤 학생 사진이 안 나와요

드라이브 학생사진/학번/에 학번.jpg가 있는지 확인. 없으면 학년-반 폴더에 이름(번호).jpg로 올리고 학기초정리 실행. 학생정보 K열 학번이 비어 있어도 안 나와요.

성적이 안 나와요

① 시트 이름이 정확한지 (성적_2027_1학년_1학기 형식) ② 그 시트 A열 학번이 채워졌는지 ③ GAS 재배포 했는지.
